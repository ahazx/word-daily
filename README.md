# 每日五词 · 背单词

一个纯静态的背单词页面：**每天 5 个词**，支持美/英发音、音标、词性、释义与例句，词书自己勾选。

**https://ahazx.github.io/word-daily/**

## 功能

### 每天 5 个

- 勾选词书后合并成一个学习池，每天固定推 5 个新词
- 同一天刷新**不会换词**，第二天自动换新词
- 跨天**不重复**，直到词库学完
- 完成当天后可选择「再背 5 个」，不打断手感

### 词书自选

- 点顶部「＋ 词书」按分类勾选，每组可一键全选
- 已选词书显示为标签，点 ✕ 移除
- 全部 72 本合计约 19MB，但**只加载勾选的那几本**，首屏依然很快

### 发音

- 每个单词提供 `🔊 US` / `🔊 UK` 两种发音，用浏览器原生语音合成，无需下载音频
- 内置**发音设置**面板：可试听并指定喜欢的语音、调节语速
- 自动避开 macOS 的趣味音效语音（Zarvox、Bubbles 等），默认选标准人声

### 学习管理

- **认识 / 不认识** 二选一，不认识的进错词本
- **错词明细**可点开：支持标记已掌握、一键「练这些错词」
- **已掌握明细**可点开：可取消掌握
- **收藏**重点单词
- 底部统计：累计已学 / 已掌握 / 连续天数 / 错词待复习
- 全部进度存在浏览器本地

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` | 翻转卡片看释义 |
| `1` 或 `J` | 不认识 |
| `2` 或 `K` | 认识 |
| `P` | 发音 |
| `F` | 收藏 |

## 文件结构

```
word-daily/
├── index.html          背单词页面（单文件，含全部样式与逻辑）
├── books/
│   ├── meta.js         词书清单（名称 / 词数 / 分类）
│   ├── tech.js         互联网科技（手写 50 词）
│   ├── hand_daily.js   日常实用词（手写 49 词）
│   └── *.js            其余 70 本词书，每本一个文件
└── .nojekyll           关闭 GitHub Pages 的 Jekyll 处理
```

词书文件按需加载，页面会按勾选情况动态引入。

## 本地使用

```bash
git clone git@github.com:ahazx/word-daily.git
cd word-daily
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000
```

也可以直接双击 `index.html`，无需服务器。
